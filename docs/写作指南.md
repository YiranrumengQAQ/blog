# ✍️ 写作指南 · 零基础也能写博客

这篇指南写给**完全不懂代码**的你。跟着做，5 分钟发布第一篇文章。

---

## 一、写文章：用「写作助手」（推荐）

博客自带的写作助手是 `editor.html`，手机和电脑浏览器都能打开。
（如果博客部署在 GitHub Pages 上，地址就是 `https://你的域名/editor.html`）

### 第 1 步：导入现有文章（第一次用要点这步）

打开写作助手，点 **「📁 导入 posts 文件夹」**，选择你博客仓库里的 `posts` 文件夹。

> 🤔 为什么要导入？
> 博客靠 `posts/manifest.json` 这个"目录文件"知道有哪些文章。
> 导入后，助手会记住已有文章，之后下载的 manifest.json 自动包含它们，**不会弄丢旧文章**。

### 第 2 步：填写文章信息

| 栏目 | 怎么填 |
| --- | --- |
| 标题 | 必填，想个好听的 ✨ |
| 日期 | 默认今天，可以改 |
| 分类 | 不填就是"默认分类"，比如填：生活 / 旅行 / 美食 |
| 标签 | 多个用逗号隔开，如：`海边, 日落` |
| 封面图 | 可不填，自动用文章第一张图 |
| 摘要 | 可不填，自动截取正文开头；也可点「✨ 自动生成」 |
| 📌 置顶 | 勾选后这篇永远显示在列表最前面 |

### 第 3 步：写正文

- 上方一排按钮就是"格式工具栏"：选中文字 → 点 **B 加粗**，文字就变粗
- 点 **🖼 图片** 会插入 `![图片描述](图片链接)`，把括号里换成你的图片链接
- 右边（手机在下方）实时显示文章在博客里的样子
- 不会 Markdown？展开「Markdown 速查表」，30 秒学会

### 第 4 步：下载 & 上传

1. 点 **「📄 下载文章 .md」** → 得到 `xxx.md`
2. 点 **「📋 下载 manifest.json」** → 得到 `manifest.json`
3. 打开 GitHub 上的你的博客仓库：
   - 点 **Add file → Upload files**
   - 把 **两个文件都拖进去**
   - 文件名输入框里：`.md` 文件的路径改成 `posts/xxx.md`；`manifest.json` 改成 `posts/manifest.json`
   - 拉到底点绿色 **Commit changes**
4. 等 1 分钟，刷新博客，新文章出现 🎉

> 💾 写到一半想休息？点「💾 存草稿」或按 `Ctrl+S`，草稿存在浏览器里，下次打开自动恢复。

## 二、图片怎么弄？（图床教程）

博客里的图片需要有一个"网址"（链接），推荐免费图床 **[imgbb.com](https://imgbb.com)**：

1. 打开 imgbb.com，把照片拖进去上传
2. 上传完成后点 **「直接链接 / Direct link」**，复制网址
3. 回到写作助手：正文里点 **🖼 图片**，把括号里的"图片链接"换成刚复制的网址
4. 想当封面的话，把网址贴到「封面图链接」输入框

> ⚠️ 换图床注意：部分图床有"防盗链"，贴过来会显示不出来，换一个图床即可。
> 图片加载失败时博客会显示友好的占位提示，不会破坏排版。

## 三、Markdown 速查表

| 想要的效果 | 就这样写 |
| --- | --- |
| **加粗** | `**重要的话**` |
| *斜体* | `*轻轻的话*` |
| 大标题 | `## 标题文字`（注意 ## 后面有空格） |
| 小标题 | `### 小标题文字` |
| 引用名言 | `> 引用的文字` |
| 插入图片 | `![描述](图片链接)` |
| 插入链接 | `[链接文字](网址)` |
| 列表 | 每行开头写 `- 内容` |
| 分割线 | 单独一行写 `---` |
| 分段 | 段落之间**空一行** |

## 四、手动改文件（进阶，可选）

不想用助手、喜欢直接改文件？也没问题：

**1. 新建文章** `posts/my-post.md`：

```markdown
---
title: 文章标题
date: 2026-05-20
category: 生活
tags: [旅行, 美食]
sticky: false
---

正文用 Markdown 写。
```

**2. 登记到目录** `posts/manifest.json`（JSON 格式，注意逗号）：

```json
[
    {
        "slug": "my-post",
        "title": "文章标题",
        "date": "2026-05-20",
        "category": "生活",
        "tags": ["旅行", "美食"]
    }
]
```

- `slug` 就是文件名（不带 .md），**必须和文件名一致**
- front matter 和 manifest 里的信息会自动合并，以文章里的 front matter 为准
- JSON 格式容易写错（少个逗号整个博客就打不开了），所以小白还是推荐用助手 😉

## 五、常见问题

**Q：文章发布了但首页没有？**
检查 `manifest.json` 里的 `slug` 和 `.md` 文件名是否完全一致；两个文件是否都在 `posts` 文件夹里。

**Q：博客打开是一片空白/提示初始化失败？**
可能是直接双击打开了 index.html（浏览器不允许本地读取文件）。部署到 GitHub Pages，或本地运行 `python3 -m http.server 8000` 再访问。

**Q：图片显示不出来？**
先在浏览器新标签页打开图片链接测试；打不开就重新上传，或换个图床。

**Q：改了博客名字在哪改？**
仓库根目录的 `config.json`，改 `blogName` 即可。

**Q：不小心把 manifest.json 改坏了？**
用写作助手重新「导入 posts 文件夹」→「下载 manifest.json」，它会生成格式正确的文件。
