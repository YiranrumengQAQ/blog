图片怎么上传？（图床教程）
  1. 打开免费图床 imgbb.com（本博客示例图片就在用）
  2. 把手机/电脑里的照片拖上去上传
  3. 上传后点「直接链接 / Direct link」，复制得到的网址
  4. 在正文里点工具栏「🖼 图片」，粘贴这个网址即可

💡 封面图链接同理，粘贴到上方「封面图链接」输入框。

上传到 GitHub 的详细步骤
  1. 下载好 你的文件名.md 和 manifest.json 两个文件
  2. 打开你的 GitHub 博客仓库页面
  3. 点右上角 Add file → Upload files
  4. 把两个文件拖到上传区（.md 和 manifest.json 都要传）
  5. ⚠️ 注意：如果页面上传的是 .md 文件，它会被放到仓库根目录——传完后把文件名输入框里的路径改成 posts/你的文件名.md；manifest.json 改成 posts/manifest.json
  6. 拉到最下面点绿色的 Commit changes 按钮
  7. 等 1 分钟刷新博客，新文章就出现啦 🎉

💡 更省事的办法：用 GitHub 桌面版 / 网页端进入 posts 文件夹后再点 Upload files，就不用改路径。

常见问题
  • 文章没出现在博客上？确认 .md 和 manifest.json 都上传到了 posts 文件夹，且 manifest.json 里有这篇文章的条目（slug 和文件名一致）。
  • 图片不显示？检查图片链接是否能直接在浏览器打开；有些图床会防盗链，换 imgbb 等图床试试。
  • 日期显示不对？日期格式请用 2026-05-19（年-月-日）。
  • 想把草稿换台电脑写？草稿存在浏览器本地，换电脑前先下载 .md 备份，或重新导入编辑。
